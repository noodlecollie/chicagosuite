* https://github.com/Alex313031/libnt5: Compatibility library fork to support building programs for Windows 2000 SP4 and Windows XP RTM - SP2.
* https://colinfinck.de/posts/modern-visual-studio-meets-ancient-windows/: Original blog post about building this library.
* https://colinfinck.de/posts/modern-visual-studio-meets-ancient-windows/: Follow-up blog post about additional compatibility with Windows NT 4.0.
* https://glizda.wordpress.com/2021/05/19/compiling-programs-for-windows-95-and-pentium-in-2021/: A comparison of different compilers for targeting a Windows 95 machine with an Intel Pentium CPU.
* https://github.com/mstorsjo/llvm-mingw: Clang/LLVM for Windows Vista upwards (can cross-compile from Linux)
* https://github.com/mon/llvm-mingw-xp: Clang/LLVM for Windows XP (can cross-compile from Linux)
* https://winlibs.com/: GCC toolchain for running on Windows (cannot cross-compile)
